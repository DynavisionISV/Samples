# Dynavision Samples

This repository contains various samples to demonstrate how to properly extend [Dynavision](https://dynavision.app/) apps.

## About these samples

The provided source code and sample apps 
- are intended to be a proof of concept
- can be used free
- are provided as is without any support and warranty
- are not regularly maintained or updated
